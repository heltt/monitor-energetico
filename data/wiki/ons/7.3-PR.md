# 7.3-PR

Fonte (versao vigente): Submódulo 7.3-PR_2024.04

## Resumo
Este submódulo estabelece os procedimentos para a verificação da conformidade das instalações de transmissão em relação aos requisitos técnicos do ONS e da ANEEL. O processo compreende a proposição de requisitos técnicos baseados no planejamento setorial, a análise e emissão de pareceres sobre o projeto básico elaborado pelos agentes, e a validação das características das instalações como efetivamente implantadas. Cabe ao ONS emitir o Certificado de Conformidade do Projeto Básico (CCPB) e o respectivo parecer de implantação, condições necessárias para etapas pré-operacionais. Adicionalmente, o documento define as diretrizes para o fornecimento, atualização e gerenciamento dos dados técnicos que compõem a Base de Dados das Instalações de Transmissão (BDIT) pelos agentes de transmissão.
