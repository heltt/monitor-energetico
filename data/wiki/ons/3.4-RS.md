# 3.4-RS

Fonte (versao vigente): Submódulo 3.4-RS_2024.07

## Resumo
O Submódulo 3.4 estabelece as responsabilidades, os produtos, os prazos e as etapas do processo de planejamento da operação elétrica com horizonte quadrimestral para a configuração da Rede de Operação do SIN. Os principais produtos gerados são as Diretrizes para Operação Elétrica com Horizonte Quadrimestral e a Base de Dados para Estudos Elétricos de Fluxo de Potência. O ONS é responsável por coordenar a elaboração dos estudos, consolidar dados, montar casos de referência e propor ações para garantir a segurança operativa e a otimização dos custos. Os agentes de transmissão, geração, distribuição e os consumidores livres devem fornecer e atualizar dados, sugerir premissas, verificar inconsistências e implantar as providências recomendadas. O documento também detalha os prazos específicos e a periodicidade anual para o envio de dados pelos agentes e a disponibilização das diretrizes pelo ONS para cada um dos três quadrimestres do ano.
