# 7.3-RS

Fonte (versao vigente): Submódulo 7.3-RS_2024.04

## Resumo
O Submódulo 7.3 estabelece os produtos, responsabilidades, prazos e etapas referentes à verificação da conformidade das instalações de transmissão que se integrarão ao Sistema Interligado Nacional (SIN). O documento define as atribuições do Operador Nacional do Sistema Elétrico (ONS) e dos agentes setoriais quanto à proposição de requisitos técnicos, análise de projetos básicos, emissão de certificados de conformidade e avaliação das instalações como efetivamente implantadas. Também são estipuladas as diretrizes para a validação qualitativa e fornecimento contínuo de dados técnicos e geográficos para a Base de Dados das Instalações de Transmissão (BDIT). Por fim, o texto detalha os prazos específicos para o cumprimento de cada uma dessas atividades pelos agentes envolvidos e pelo ONS.
