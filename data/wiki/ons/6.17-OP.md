# 6.17-OP

Fonte (versao vigente): Submódulo 6.17-OP_2026.04

## Resumo
Este submódulo estabelece os procedimentos e as responsabilidades para a coleta de dados de medição para faturamento no Sistema de Medição para Faturamento (SMF). A coleta pode ocorrer de forma direta pela CCEE, de forma passiva por meio de arquivos XML disponibilizados pelo agente responsável pelo SMF, ou de forma local nas instalações quando necessário. A CCEE é responsável por coletar, validar, armazenar e repassar os dados ao ONS conforme o Acordo Operacional CCEE/ONS. Além disso, a CCEE, o ONS e os agentes responsáveis pelo SMF devem manter os dados dos medidores armazenados em seus bancos de dados pelo período de 5 anos.
