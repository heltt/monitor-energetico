# 7.1-PR

Fonte (versao vigente): Submódulo 7.1-PR_2026.04

## Resumo
O Submódulo 7.1 estabelece os procedimentos para o acesso às instalações de transmissão do Sistema Interligado Nacional (SIN), cujas tratativas ocorrem por meio de sistema computacional do ONS. O documento detalha as etapas e regras para a realização de consultas de acesso, emissão de documentos equivalentes de acesso para geradores e emissão de pareceres técnicos de impacto para distribuidoras. Também define os requisitos para a solicitação de Parecer de Acesso, o que inclui a apresentação de dados, estudos elétricos de integração, informações específicas conforme o tipo de instalação e a prestação de garantia financeira (GPA) para empreendimentos de geração. Adicionalmente, o processo garante a reserva de margem de transmissão com base na ordem cronológica do protocolo e aborda os procedimentos para desativação ou reconexão de instalações a pedido do acessante.
