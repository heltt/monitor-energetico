# 2.14-RQ

Fonte (versao vigente): Submódulo 2.14-RQ_2022.11

## Resumo
Este submódulo estabelece os requisitos mínimos para o Sistema de Medição para Faturamento (SMF), abrangendo medidores, transformadores para instrumentos, cabeamento, comunicação de dados e localização dos pontos de medição. O SMF deve ser independente para cada circuito, atendendo a normas da ABNT e da IEC, com capacidade para medir e registrar grandezas elétricas nos diferentes sentidos do fluxo de potência. Os medidores devem possuir classe de exatidão adequada, memória de massa, relógio sincronizado e portas de comunicação independentes para a CCEE e os agentes envolvidos. O documento também define regras para preservação de registros, garantias de inviolabilidade e arquitetura básica para a coleta de dados de faturamento.
